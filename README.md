# Abarrotera-libertad

Sitio web de Abarrotes y Cremería Libertad.

## Publicación

El archivo `index.html` está en la raíz para que GitHub Pages pueda servirlo directamente.

Para activar GitHub Pages en este repositorio: abre **Settings → Pages**, selecciona **Deploy from a branch**, elige `main` y la carpeta `/(root)`, y guarda.
